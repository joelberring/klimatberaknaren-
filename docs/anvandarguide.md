# Användarguide

## Så använder du kalkylatorn

1. Välj byggnadstyp.
2. Ange bruttoarea och byggår.
3. Välj stommaterial, energistandard och uppvärmning.
4. Ange vid behov specifik energianvändning och U-värden.
5. Klicka på `Beräkna klimatpåverkan`.

## Vad du får tillbaka

- total embodied klimatpåverkan
- driftutsläpp per år
- driftutsläpp över 50 år
- uppdelning per kategori
- centrala antaganden
- källor och versionsinfo

## Tolkning

- Resultaten är schablonbaserade och lämpar sig bäst för tidig analys och jämförelse.
- Osäkerhetsintervallet visar att faktiska materialval, system och driftmönster kan ge andra utfall.
- Om du anger egen specifik energianvändning får den företräde framför referensschablonen.
